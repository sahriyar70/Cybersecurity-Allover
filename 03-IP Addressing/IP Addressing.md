# IP Addressing, CIDR, Ports & Protocols (Cybersecurity Focus)
 
**বিষয়:** IPv4 vs IPv6, Public vs Private IP, CIDR Subnetting, Ports & Wireshark Concepts

---

## Overview
নেটওয়ার্ক সিকিউরিটি এবং এথিক্যাল হ্যাকিংয়ের জন্য IP Addressing, Subnetting (CIDR), এবং Port-এর ধারণাগুলো জানা অপরিহার্য। নেটওয়ার্কে ডেটা প্যাকেট ট্রেস করা, পোর্ট স্ক্যানিং (Nmap) করা এবং আইপি ট্র্যাক করার জন্য এই কনসেপ্টগুলো সরাসরি ব্যবহৃত হয়।

## IPv4 vs IPv6 Addressing

| বৈশিষ্ট্য | IPv4 | IPv6 |
| :--- | :--- | :--- |
| **আকার (Size)** | 32-bit address | 128-bit address |
| **মোট আইপি সংখ্যা** | ~৪.৩ বিলিয়ন ($2^{32}$) | ~$3.4 \times 10^{38}$ ($2^{128}$) |
| **ফরম্যাট** | ডট-ডেসিমেল (যেমন: `192.168.1.1`) | হেক্সাডেসিমেল (যেমন: `2001:db8::ff00:42`) |
| **কনফিগারেশন** | Manual / DHCP | Auto-configuration (SLAAC) / DHCPv6 |
| **ইনবিল্ট সিকিউরিটি** | সিকিউরিটি ঐচ্ছিক (IPsec পরে যুক্ত করা হয়েছে) | **IPsec** বাই-ডিফল্ট আর্কিটেকচারের সাথে বিল্ট-ইন |
| **NAT-এর প্রয়োজন** | আইপি সংকটের কারণে NAT আবশ্যক | বিশাল সংখ্যার কারণে NAT-এর প্রয়োজন নেই |

## Public IP vs Private IP Address

### ১. Public IP Address
* **সংজ্ঞা:** বিশ্বব্যাপী ইন্টারনেটে যেকোনো ডিভাইসকে চিহ্নিত করার জন্য ব্যবহৃত ইউনিক আইপি।
* **রাউটিং:** এটি ইন্টারনেটে সরাসরি রাউট হয় (Globally Routable)।
* **প্রদানকারী:** ISP (Internet Service Provider) এটি বরাদ্দ করে।

### ২. Private IP Address
* **সংজ্ঞা:** কেবল লোকাল নেটওয়ার্ক (LAN)-এর ভেতরের ডিভাইসগুলোর সাথে যোগাযোগের জন্য ব্যবহৃত হয়।
* **রাউটিং:** এটি ইন্টারনেটে সরাসরি প্রবেশ করতে পারে না (NAT ব্যবহার করে বাইরে যেতে হয়)।
* **RFC 1918 নির্ধারিত Private IP Ranges:**
  * **Class A:** `10.0.0.0` – `10.255.255.255` (বিশাল এন্টারপ্রাইজ নেটওয়ার্ক)
  * **Class B:** `172.16.0.0` – `172.31.255.255` (মাঝারি নেটওয়ার্ক)
  * **Class C:** `192.168.0.0` – `192.168.255.255` (হোম/স্মল অফিস নেটওয়ার্ক)

## CIDR Notation & Subnetting (Classless Inter-Domain Routing)

CIDR হলো আইপি অ্যাড্রেস লেখার একটি আধুনিক পদ্ধতি যা নেটওয়ার্ক এবং হোস্ট অংশকে পৃথক করতে **Slash (/) Notation** ব্যবহার করে।

* **Subnet Mask:** আইপি অ্যাড্রেসের কতটুকু অংশ Network ID আর কতটুকু Host ID তা প্রকাশ করে।
* **উদাহরণ:** `192.168.1.0/24`
  * `/24` মানে প্রথম ২৪ বিট হলো Network Address।
  * বাকি ৮ বিট ($32 - 24 = 8$) হোস্ট বা ডিভাইসের জন্য বরাদ্দ।
  * মোট হোস্ট সংখ্যা: $2^8 - 2 = 254$ টি (১টি Network ID এবং ১টি Broadcast ID বাদ পড়ে)।

### সাধারণ CIDR প্রেফিক্স টেবিল:

| CIDR Prefix | Subnet Mask | usable IPs (হোস্ট সংখ্যা) |
| :--- | :--- | :--- |
| **/32** | 255.255.255.255 | 1 (নির্দিষ্ট একটি ডিভাইস/Host) |
| **/30** | 255.255.255.252 | 2 (Point-to-Point রাউটার লিংক) |
| **/24** | 255.255.255.0 | 254 (স্ট্যান্ডার্ড লোকাল নেটওয়ার্ক) |
| **/16** | 255.255.0.0 | 65,534 (বড় এন্টারপ্রাইজ কোম্পানি) |
| **/8** | 255.0.0.0 | 16,777,214 (বিশাল কর্পোরেট/ISP) |

> **সিকিউরিটি নোট:** ফায়ারওয়াল রুলস (Firewall Rules) লেখার সময় `192.168.1.0/24` ব্লকিং রুল দিলে পুরো সাবনেটের ২৫৪টি আইপি ব্লক হয়ে যায়, আর `192.168.1.50/32` দিলে কেবল ওই একটি ডিভাইস ব্লক হয়।

## Network Ports (নেটওয়ার্ক পোর্টস)

আইপি অ্যাড্রেস যদি হয় একটি বহুতল ভবনের ঠিকানা, তবে পোর্ট নাম্বার হলো সেই ভবনের ভেতরের আলাদা আলাদা **ফ্ল্যাট নম্বর**। পোর্ট দিয়ে বোঝা যায় রিকোয়েস্টটি কোন নির্দিষ্ট সার্ভিসে যাচ্ছে।

* **মোট পোর্ট সংখ্যা:** ০ থেকে ৬৫,৫৩৫ টি ($2^{16}$)।
* **পোর্টের শ্রেণীবিভাগ:**
  1. **Well-Known Ports (0 - 1023):** বিশ্বজুড়ে স্ট্যান্ডার্ড সার্ভিসগুলোর জন্য সংরক্ষিত (যেমন: HTTP, SSH)।
  2. **Registered Ports (1024 - 49151):** নির্দিষ্ট সফটওয়্যার কোম্পানি বা অ্যাপ্লিকেশনের জন্য রেজিস্টার্ড (যেমন: MySQL-3306)।
  3. **Dynamic / Ephemeral Ports (49152 - 65535):** ক্লায়েন্ট ডিভাইস সাময়িকভাবে আউটগোয়িং কানেকশনের জন্য ব্যবহার করে।

## Additional Cyber-Relevant Concepts (জরুরি অতিরিক্ত বিষয়াবলি)

### ১. Loopback Address / Localhost (`127.0.0.1` বা `::1`)
* নিজের ডিভাইসকে নির্দেশ করার জন্য ব্যবহৃত হয়। কোনো সার্ভার স্থানীয়ভাবে টেস্ট করতে বা ইন্টারনাল সার্ভিস চেক করতে এটি ব্যবহৃত হয়।

### ২. APIPA (Automatic Private IP Addressing)
* যদি কোনো ডিভাইস DHCP সার্ভার থেকে IP না পায়, তখন উইন্ডোজ স্বয়ংক্রিয়ভাবে **`169.254.x.x`** রেঞ্জের একটি আইপি অ্যাসাইন করে। নেটওয়ার্কে কোনো সমস্যা হলে এই আইপি দেখে তা বোঝা যায়।

### ৩. Special IP Ranges for Pentesting
* **`0.0.0.0/0`:** যেকোনো আইপি/সব আইপি বোঝাতে ফায়ারওয়াল রুলে ব্যবহৃত হয়।
* **Broadcast Address:** সাবনেটের শেষ আইপি (যেমন `192.168.1.255`), যা দিয়ে ওই নেটওয়ার্কের সব ডিভাইসে বার্তা পাঠানো যায়।

## Key Security Takeaways
1. **IP Scanning (Nmap):** একজন হ্যাকার প্রথমে সাবনেট স্ক্যান (CIDR ধরে) করে কোন কোন আইপি লাইভ আছে তা বের করে।
2. **Port Scanning:** আইপি পাওয়ার পর открытый (Open) পোর্ট স্ক্যান করা হয় সার্ভিস ও সফটওয়্যার ভার্সন চেনার জন্য।
3. **Firewall Rule Management:** সঠিক CIDR রেঞ্জ এবং নির্দিষ্ট Port বন্ধ রেখে **Attack Surface** নিয়ন্ত্রণ করা হয়।
