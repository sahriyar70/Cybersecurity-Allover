# Web Reconnaissance & Directory Busting

## ১. Web Reconnaissance (ওয়েব রিকন)

ওয়েব রিকন হলো কোনো ওয়েবসাইটের গঠন, ব্যবহৃত প্রযুক্তি, ডিরেক্টরি এবং সম্ভাব্য নিরাপত্তা দুর্বলতা সম্পর্কে তথ্য সংগ্রহের প্রক্রিয়া।

**প্রধান টুলস:**

* **HTTrack:** ওয়েবসাইটের কপি তৈরি করে অফলাইনে দেখার জন্য।
* **CeWL:** ওয়েবসাইটের কনটেন্ট থেকে কাস্টম ওয়ার্ডলিস্ট তৈরি করে।
* **Gobuster:** লুকানো ডিরেক্টরি, ফাইল ও সাবডোমেইন খুঁজে বের করে।
* **FFUF:** ওয়েবসাইটের পাথ, ফাইল, প্যারামিটার ও ভার্চুয়াল হোস্ট খুঁজতে ফাজিং করে।

## ২. HTTrack

**কাজ:** ওয়েবসাইটের লোকাল কপি তৈরি করে অফলাইনে দেখার সুযোগ দেয়।

**ব্যবহার:**

* ওয়েবসাইটের গঠন বিশ্লেষণ।
* অফলাইনে ওয়েবপেজ দেখা।
* প্রকাশ্যে থাকা পেজ পর্যালোচনা।

**মনে রাখবে:** এটি ওয়েবসাইটের সব সার্ভার-সাইড ফাংশন বা ডেটাবেস কপি করতে পারে না।

## ৩. CeWL (Custom Word List Generator)

**কাজ:** ওয়েবসাইটের লেখা থেকে শব্দ সংগ্রহ করে কাস্টম ওয়ার্ডলিস্ট তৈরি করে।

**কমান্ড:**

```bash
cewl https://example.com -w wordlist.txt
```

* `-w`: ওয়ার্ডলিস্ট ফাইলে সংরক্ষণ করে।
* অনুমোদিত পাসওয়ার্ড অডিটিং ও নিরাপত্তা পরীক্ষায় কাজে লাগে।

## ৪. Directory Busting

ডিরেক্টরি বাস্টিং হলো ওয়ার্ডলিস্ট ব্যবহার করে ওয়েব সার্ভারের লুকানো ডিরেক্টরি ও ফাইল খুঁজে বের করার পদ্ধতি।

**সাধারণ টুলস:**

* Gobuster
* FFUF
* Dirsearch
* Feroxbuster

**উদাহরণ:**

* `/admin`
* `/backup`
* `/uploads`
* `/robots.txt`

## ৫. Gobuster

**কাজ:** ওয়ার্ডলিস্ট ব্যবহার করে ওয়েবসাইটের ডিরেক্টরি ও ফাইল খুঁজে বের করে।

**কমান্ড:**

```bash
gobuster dir -u https://example.com -w wordlist.txt
```

* `dir`: ডিরেক্টরি ও ফাইল খোঁজার মোড।
* `-u`: টার্গেট ওয়েবসাইটের URL।
* `-w`: ওয়ার্ডলিস্টের পাথ।

## ৬. FFUF (Fuzz Faster U Fool)

**কাজ:** ওয়েবসাইটের লুকানো পাথ, ফাইল, প্যারামিটার ও ভার্চুয়াল হোস্ট খুঁজতে ব্যবহৃত হয়।

**ডিরেক্টরি খোঁজা:**

```bash
ffuf -u https://example.com/FUZZ -w wordlist.txt
```

* `FUZZ`: ওয়ার্ডলিস্টের প্রতিটি শব্দ দিয়ে প্রতিস্থাপিত হয়।
* `-u`: টার্গেট URL।
* `-w`: ওয়ার্ডলিস্টের পাথ।

**প্যারামিটার খোঁজার উদাহরণ:**

```bash
ffuf -u "https://example.com/?FUZZ=test" -w params.txt
```

## ৭. টুলগুলোর পার্থক্য

| টুল      | প্রধান কাজ               |
| -------- | ------------------------ |
| HTTrack  | ওয়েবসাইটের কপি তৈরি      |
| CeWL     | কাস্টম ওয়ার্ডলিস্ট তৈরি  |
| Gobuster | ডিরেক্টরি ও ফাইল খোঁজা   |
| FFUF     | বিভিন্ন ধরনের ওয়েব ফাজিং |

**নিরাপত্তা নির্দেশনা:** শুধু নিজের ওয়েবসাইট বা অনুমতিপ্রাপ্ত সিস্টেমে এসব টুল ব্যবহার করবে। অতিরিক্ত রিকোয়েস্ট পাঠিয়ে সার্ভারের ওপর চাপ সৃষ্টি করা থেকে বিরত থাকবে।
