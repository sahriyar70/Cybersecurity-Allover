# Cybersecurity Enumeration & Information Gathering Guide

## ১. Enumeration কী?

Enumeration হলো সাইবার সিকিউরিটি রিকনেসান্সের একটি প্রক্রিয়া, যার মাধ্যমে কোনো টার্গেট সিস্টেম, ডোমেইন, ওয়েবসাইট বা নেটওয়ার্ক সম্পর্কে বিস্তারিত তথ্য সংগ্রহ করা হয়।

**সাধারণত যেসব তথ্য সংগ্রহ করা হয়:**
- ডোমেইন ও DNS রেকর্ড
- IP Address ও Subdomain
- ওপেন পোর্ট ও সার্ভিস
- Web Application Firewall (WAF)
- প্রকাশ্যে থাকা সার্টিফিকেট ও ডিরেক্টরি

> **নোট:** শুধু নিজের সিস্টেম অথবা অনুমতিপ্রাপ্ত সিস্টেমে এনুমারেশন ও নিরাপত্তা পরীক্ষা করবে।

---

## ২. `apt` দিয়ে টুল ইনস্টল

`apt` হলো Debian-ভিত্তিক Linux ডিস্ট্রিবিউশনের প্যাকেজ ম্যানেজার। Kali Linux ও Ubuntu-তে এটি ব্যবহার করা হয়।

```bash
sudo apt update
sudo apt install <tool_name>
```

- `sudo` — প্রশাসনিক অনুমতিতে কমান্ড চালায়।
- `apt update` — প্যাকেজের তালিকা আপডেট করে।
- `apt install` — নির্দিষ্ট সফটওয়্যার ইনস্টল করে।

## ৩. Enumeration Tools ও Commands

### A. WHOIS

**কাজ:** ডোমেইনের রেজিস্ট্রেশন-সংক্রান্ত প্রকাশ্য তথ্য সংগ্রহ করে।

```bash
whois example.com
```

**যে তথ্য পাওয়া যেতে পারে:**
- ডোমেইন রেজিস্ট্রার
- রেজিস্ট্রেশন ও মেয়াদ শেষ হওয়ার তারিখ
- Name Server
- প্রকাশ্যে থাকা রেজিস্ট্র্যান্টের তথ্য

### B. Host

**কাজ:** DNS Lookup এবং Reverse DNS Lookup করে।

```bash
host example.com
host 93.184.216.34
```

- প্রথম কমান্ড — ডোমেইনের DNS তথ্য বের করে।
- দ্বিতীয় কমান্ড — IP Address-এর সঙ্গে যুক্ত Reverse DNS নাম খোঁজে।

### C. DNSrecon

**কাজ:** DNS রেকর্ড, সাবডোমেইন এবং সম্ভাব্য DNS কনফিগারেশন সমস্যা শনাক্ত করে।

**ইনস্টল:**

```bash
sudo apt install dnsrecon
```

**কমান্ড:**

```bash
dnsrecon -d example.com
dnsrecon -d example.com -t std
dnsrecon -d example.com -t axfr
```

**গুরুত্বপূর্ণ ফ্ল্যাগ:**
- `-d` — টার্গেট ডোমেইন নির্ধারণ করে।
- `-t` — এনুমারেশনের ধরন নির্ধারণ করে।
- `-r` — Reverse Lookup-এর জন্য IP Range নির্ধারণ করে।

**নোট:** `axfr` দিয়ে DNS Zone Transfer পরীক্ষা করার আগে অনুমতি নিশ্চিত করবে।

### D. WAFW00F

**কাজ:** কোনো ওয়েবসাইটে Web Application Firewall (WAF) ব্যবহৃত হচ্ছে কি না, তা শনাক্ত করার চেষ্টা করে।

**ইনস্টল:**

```bash
sudo apt install wafw00f
```

**কমান্ড:**

```bash
wafw00f https://example.com
wafw00f -a https://example.com
```

**গুরুত্বপূর্ণ ফ্ল্যাগ:**
- `-a` — শনাক্ত করা সম্ভব এমন সব WAF পরীক্ষা করার চেষ্টা করে।
- `-v` — বিস্তারিত আউটপুট দেখায়।
- `-l` — সমর্থিত WAF-এর তালিকা দেখায়।

### E. Sublist3r

**কাজ:** বিভিন্ন সমর্থিত পাবলিক সোর্স থেকে সাবডোমেইন সংগ্রহ করে।

**ইনস্টল:**

```bash
sudo apt install sublist3r
```

**কমান্ড:**

```bash
sublist3r -d example.com
sublist3r -d example.com -o subdomains.txt
sublist3r -d example.com -b
```

**গুরুত্বপূর্ণ ফ্ল্যাগ:**
- `-d` — টার্গেট ডোমেইন নির্ধারণ করে।
- `-b` — সমর্থিত হলে Brute-force পদ্ধতিতে সাবডোমেইন খোঁজে।
- `-p` — সমর্থিত হলে নির্দিষ্ট পোর্ট নির্ধারণ করে।
- `-o` — ফলাফল ফাইলে সংরক্ষণ করে।

### F. Certificate Transparency — crt.sh

**কাজ:** প্রকাশ্যে লগ করা SSL/TLS সার্টিফিকেট থেকে সাবডোমেইনের তথ্য খুঁজে পেতে সাহায্য করে।

ওয়েবসাইট: https://crt.sh

**ব্যবহার:**
1. ওয়েবসাইটে প্রবেশ করো।
2. সার্চ বক্সে ডোমেইন লিখো, যেমন `example.com`।
3. পাওয়া সার্টিফিকেটের তথ্য ও সংশ্লিষ্ট সাবডোমেইন পরীক্ষা করো।

### G. Web Check

**কাজ:** একটি ওয়েবসাইটের বিভিন্ন প্রযুক্তিগত তথ্য পরীক্ষা করে।

ওয়েবসাইট: https://web-check.xyz

**যে তথ্য পাওয়া যেতে পারে:**
- DNS রেকর্ড
- HTTP Security Headers
- TLS সার্টিফিকেটের তথ্য
- সার্ভার ও ওয়েবসাইটের অন্যান্য প্রযুক্তিগত তথ্য

**ব্যবহার:** ওয়েবসাইটে প্রবেশ করে অনুমতিপ্রাপ্ত টার্গেটের URL দিয়ে উপলভ্য পরীক্ষাগুলো চালাও।

### H. HTTrack

**কাজ:** ওয়েবসাইটের অ্যাক্সেসযোগ্য ফাইল ডাউনলোড করে অফলাইনে দেখার জন্য স্থানীয় কপি তৈরি করে।

**ইনস্টল:**

```bash
sudo apt install httrack
```

**কমান্ড:**

```bash
httrack https://example.com -O ./website-copy
```

**গুরুত্বপূর্ণ ফ্ল্যাগ:**
- `-O` — ডাউনলোড করা ফাইল সংরক্ষণের ডিরেক্টরি নির্ধারণ করে।

**নোট:** HTTrack মূলত ওয়েবসাইটের অ্যাক্সেসযোগ্য রিসোর্স কপি করে। এটি সার্ভারের মূল Backend Source Code ডাউনলোড করে না।

## ৪. Wordlist কী?

Wordlist হলো একটি টেক্সট ফাইল, যেখানে সম্ভাব্য শব্দ, ইউজারনেম, পাসওয়ার্ড, ডিরেক্টরি বা সাবডোমেইনের তালিকা থাকে। সাধারণত প্রতিটি শব্দ আলাদা লাইনে লেখা হয়।

### A. নিজে Wordlist তৈরি

```bash
nano custom_list.txt
```

ফাইলের মধ্যে উদাহরণ হিসেবে লেখো:

```text
admin
login
test
dashboard
```

**Nano-তে সেভ করার নিয়ম:**
- `Ctrl + O` — ফাইল সেভ করো।
- `Enter` — ফাইলের নাম নিশ্চিত করো।
- `Ctrl + X` — Nano থেকে বের হও।

### B. আগে থেকে থাকা Wordlist খোঁজা

Kali Linux-এ সাধারণত Wordlist রাখার একটি প্রচলিত ডিরেক্টরি:

```bash
ls /usr/share/wordlists/
```

এখানে `rockyou.txt` থাকতে পারে। কিছু ইনস্টলেশনে এটি ব্যবহারের আগে Extract করতে হয়।

### C. Crunch দিয়ে Wordlist তৈরি

**কাজ:** নির্দিষ্ট দৈর্ঘ্য ও ক্যারেক্টার ব্যবহার করে বিভিন্ন কম্বিনেশন তৈরি করে।

**ইনস্টল:**

```bash
sudo apt install crunch
```

**সিনট্যাক্স:**

```bash
crunch <min_length> <max_length> <characters> -o output.txt
```

**উদাহরণ:**

```bash
crunch 4 6 abc123 -o mylist.txt
```

এই কমান্ডটি `abc123`-এর অক্ষরগুলো ব্যবহার করে ৪ থেকে ৬ ক্যারেক্টার দৈর্ঘ্যের কম্বিনেশন তৈরি করবে এবং `mylist.txt` ফাইলে সংরক্ষণ করবে।

**সতর্কতা:** বড় Wordlist তৈরি করলে অনেক RAM, স্টোরেজ ও সময় লাগতে পারে। তাই দৈর্ঘ্য ও ক্যারেক্টারের সংখ্যা প্রয়োজন অনুযায়ী নির্ধারণ করবে।

## ৫. গুরুত্বপূর্ণ টুলসের সংক্ষিপ্ত তালিকা

| টুল | প্রধান কাজ |
|---|---|
| `whois` | ডোমেইনের রেজিস্ট্রেশন তথ্য |
| `host` | DNS ও Reverse DNS Lookup |
| `dnsrecon` | DNS Enumeration |
| `wafw00f` | WAF শনাক্তকরণ |
| `sublist3r` | Subdomain Discovery |
| `crt.sh` | সার্টিফিকেট থেকে তথ্য সংগ্রহ |
| `Web Check` | ওয়েবসাইটের প্রযুক্তিগত তথ্য পরীক্ষা |
| `HTTrack` | ওয়েবসাইটের স্থানীয় কপি তৈরি |
| `Crunch` | Wordlist তৈরি |

## ৬. নিরাপদে কাজ করার নিয়ম

- সম্ভব হলে প্রথমে Passive Reconnaissance দিয়ে শুরু করো।
- পাওয়া তথ্য যাচাই করে সিদ্ধান্ত নাও।
- অনুমতি ছাড়া অন্যের সিস্টেমে স্ক্যান বা আক্রমণ চালাবে না।
- সংগৃহীত তথ্য নিরাপদে রাখবে এবং ব্যক্তিগত গোপনীয়তা রক্ষা করবে।
- Wordlist দায়িত্বশীলভাবে ব্যবহার করবে।
